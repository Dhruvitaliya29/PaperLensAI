# PaperLens AI

## Project Title

PaperLens AI: An Intelligent Research Document Analysis and Literature Review Assistant Using Retrieval-Augmented Generation (RAG)

## Description

PaperLens AI is an AI-powered research workspace that helps researchers, students, and professionals analyze multiple research documents using Retrieval-Augmented Generation (RAG).

The system supports semantic search, document comparison, literature review generation, and source-grounded question answering.

## Technologies

- Python
- LangChain
- FastAPI
- Streamlit
- FAISS
- Sentence Transformers
- PyMuPDF
- Hugging Face Embeddings
